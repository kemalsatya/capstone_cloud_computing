# Common Infrastructure Evidence Template

Store only selected, interpreted evidence. Do not dump every command output.

Suggested files:

- `versions.txt`
- `core-services.txt`
- `gitea-repositories.md`
- `ci-run.md`
- `image-and-scan.md`
- `argocd-sync.md`
- `kubernetes-state.md`
- `iam-test.md`
- `metrics-dashboard.md`
- `failure-test.md`
- `backup-restore.md`
- `capacity-cost.md`

For every artifact record: scope, owner, version/source, timestamp, method, observation, interpretation, limitation, and decision supported.
